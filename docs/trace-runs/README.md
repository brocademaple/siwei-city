# 思维链路留痕

这个目录保存可公开查看、可复跑的思维链路记录。它记录的是产品化工作轨迹：输入、关键假设、模式选择、观点建筑、居民圆桌、采纳动作、道路关系、巡城检查、归档输出和项目交互。

说明：这里不会保存模型私有的逐字内部思维链。为了可审计和可交付，项目保留的是可解释的外部推理记录、决策依据和操作日志。

## 复跑命令

```bash
npm run trace:thinking
```

输出文件：

- `latest-two-chain-runs.md`
- `latest-two-chain-runs.json`
- `YYYY-MM-DD-two-chain-runs.md`
- `YYYY-MM-DD-two-chain-runs.json`

## 当前两条链路

1. 探索模式：`我想做一个面向独居女性的夜间安全产品`
2. 决策模式：`我想判断一个 AI 简历工具值不值得做`

这两条链路覆盖了思维城邦的核心闭环：从模糊议题进入地图、让多角色居民互相回应、把来函采纳入城、由巡城官检查结构断点，最后沉淀成报告和下一步行动。
